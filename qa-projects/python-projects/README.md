# python-projects

Python projects demonstrating programming fundamentals, problem-solving, and code organization.

## Structure
| Folder | Topic |
|--------|-------|
| `basics/` | Variables, data types, conditionals, loops |
| `functions/` | Defining functions, arguments, return values, scope |
| `oop/` | Classes and objects — a small BankAccount example |
| `file_handling/` | Reading and writing text files |
| `problem_solving/` | Classic practice problems with clean solutions |
| `tests/` | pytest unit tests for the code above |

## Run it
```bash
pip install -r requirements.txt
python -m pytest -q          # run the tests
python basics/loops.py       # run any example directly
python problem_solving/solutions.py
```
