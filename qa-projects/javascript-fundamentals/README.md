# javascript-fundamentals

JavaScript fundamentals practice covering functions, arrays, objects, JSON, error handling, and asynchronous programming.

## Run it
```bash
npm test        # uses the built-in Node.js test runner — no dependencies to install
node src/02-functions.js   # run any topic file directly
```

| File | Topic |
|------|-------|
| `src/01-variables.js` | let / const, types, template strings |
| `src/02-functions.js` | Function declarations, arrow functions, defaults |
| `src/03-arrays.js` | map, filter, reduce, find, sorting |
| `src/04-objects.js` | Objects, destructuring, spread |
| `src/05-json.js` | JSON.parse / JSON.stringify |
| `src/06-error-handling.js` | try/catch, throwing errors |
| `src/07-async.js` | Promises and async/await |
| `tests/fundamentals.test.js` | Tests for all of the above |
