# Functional Requirements — SauceDemo Practice Store

| ID | Requirement |
|----|-------------|
| REQ-01 | A registered user can log in with a valid username and password and lands on the Inventory page. |
| REQ-02 | Invalid, empty, or locked-out credentials show a clear error and do not log the user in. |
| REQ-03 | The Inventory page lists 6 products with name, description, price, image, and an Add to Cart button. |
| REQ-04 | Products can be sorted by name (A–Z, Z–A) and by price (low–high, high–low). |
| REQ-05 | A user can open a product detail page and return to the inventory list. |
| REQ-06 | A user can add and remove products; the cart badge always shows the correct count. |
| REQ-07 | The Cart page lists the selected products with quantity and price, and supports removing items and continuing shopping. |
| REQ-08 | Checkout Step One requires first name, last name, and postal code; missing data shows a specific error. |
| REQ-09 | Checkout Step Two (Overview) shows the items, item total, tax (8%), and total (item total + tax). |
| REQ-10 | Finishing checkout shows an order-complete confirmation and empties the cart. |
| REQ-11 | A logged-in user can log out from the side menu and is returned to the login page. |
| REQ-12 | Product images and Add to Cart must behave the same for every standard user persona. |
