# User Stories

- **SHOP-102** As a shopper, I want to log in securely so that I can see the product catalog.
- **SHOP-105** As a shopper, I want to sort products by price so that I can find the cheapest item first.
- **SHOP-110** As a shopper, I want to add and remove items so that my cart only holds what I intend to buy.
- **SHOP-118** As a shopper, I want a clear checkout total including tax so that I know exactly what I will pay.
- **SHOP-121** As a shopper, I want an order confirmation so that I know my purchase completed.
- **SHOP-124** As a shopper, I want to log out so that my session is not left open on a shared machine.
